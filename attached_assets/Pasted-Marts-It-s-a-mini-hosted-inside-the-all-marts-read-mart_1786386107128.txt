Important Replit database limitation
Replit provides one built-in PostgreSQL database per Replit App. A folder named marts inside the AllMart App cannot automatically receive a second independent Replit Postgres database.
To use a truly separate Replit Postgres database, Marts must be created as its own Replit App. That separate App will receive its own database connection, which can be configured as:
MARTS_DATABASE_URL=<separate Marts Replit Postgres connection>

The code can still be developed under:
allmart/marts/

and deployed to the VPS as an independent service. The important part is that the connection string points to the Marts database, never the AllMart database.
If the Marts service is eventually hosted only on the VPS, the separate database could also be a dedicated PostgreSQL database or a separate managed PostgreSQL project. The application interface will remain MARTS_DATABASE_URLeither way.
