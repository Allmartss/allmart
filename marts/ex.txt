Marts Extraction Status
=======================

This file records the current state of the isolated Marts application inside
the root-level `marts/` folder.

WHAT HAS BEEN DONE
------------------

1. Marts was extracted into its own folder beside AllMart. It has an
   independent FastAPI backend, React/Vite frontend, database configuration,
   authentication, environment namespace, logs, and service workflow.

2. The extracted application includes:

   - FastAPI backend under `marts/src/`
   - React/Vite frontend under `marts/frontend/`
   - SQLAlchemy models and Alembic files
   - Authentication, market data, AI, wallet, positions, paper trading,
     notifications, and admin features
   - Marts operational scripts and documentation

3. Unrelated mobile, Evolution/WhatsApp service source, Git history, backups,
   monitoring deployment files, and the original Streamlit UI were not copied.

4. Database isolation is configured as:

   - First choice: `MARTS_DATABASE_URL`
   - Approved fallback: `DATABASE_URL`
   - `SUPABASE_DB_URL` is not read by Marts
   - Startup fails clearly when no approved database URL exists

5. Marts JWT signing uses `MARTS_JWT_SECRET` and does not use AllMart's session
   secret. Optional AI, broker, storage, email, messaging, and public URL
   settings use `MARTS_*` names.

6. The frontend uses `/marts/` as its base path:

   - Pages: `/marts/...`
   - REST API: `/marts/api/...`
   - WebSockets: `/marts/ws/...`

7. The production frontend was installed and built successfully from
   `marts/frontend/`. FastAPI serves the resulting `frontend/dist` output.

8. Reverse-proxy routing was added without changing AllMart's existing paths:

   - `/` remains AllMart
   - `/api/...` remains AllMart API
   - `/marts` redirects to `/marts/`
   - `/marts/` serves Marts
   - `/marts/api/...` reaches the private Marts REST API
   - `/marts/ws/...` reaches the private Marts WebSocket API

9. A separate `marts: FastAPI` workflow was configured on private port `8090`.
   It is independently restartable from AllMart.

10. Runtime issues found during verification were fixed:

    - Added the PostgreSQL `psycopg2-binary` driver.
    - Added the missing `Response` import used by logout.
    - Replaced remaining legacy optional integration names with `MARTS_*`.
    - Confirmed FastAPI imports and startup schema initialization against the
      dedicated Marts database.

11. Prometheus and Grafana are being removed from Marts to keep the deployment
    image small. They are not required for the initial authentication, market,
    and paper-trading release.

12. A separate Alembic run is intentionally skipped. FastAPI performs the
    existing non-destructive schema creation and incremental startup changes.
