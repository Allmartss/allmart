Marts Extraction Status
=======================

This file explains what has been done inside the root-level `marts/` folder
and what still needs to be completed.

WHAT HAS BEEN DONE
------------------

1. A separate `marts/` folder was created at the AllMart project root.
   The existing AllMart ecommerce folders and application code were not
   intentionally merged with Marts.

2. The public FinAi repository was inspected and the main web application was
   extracted into Marts:

   - FastAPI backend source under `marts/src/`
   - React/Vite web frontend under `marts/frontend/`
   - SQLAlchemy/Alembic database files under `marts/migrations/`
   - Python dependency list in `marts/requirements.txt`
   - Admin setup script in `marts/setup_admin.py`

3. Unrelated source was not copied into Marts:

   - Mobile/Expo application
   - Evolution/WhatsApp service
   - Git history
   - Backup data
   - Monitoring deployment files and separate monitoring services
   - The source repository's local Streamlit UI

4. Marts database selection was separated from the AllMart application:

   - First choice: `MARTS_DATABASE_URL`
   - Fallback: `DATABASE_URL`
   - Marts fails clearly if neither database variable is available

5. Marts JWT signing was renamed to use `MARTS_JWT_SECRET`.
   The extracted backend does not intentionally use the AllMart session secret.

6. The frontend was changed to use the `/marts/` base path:

   - Web pages: `/marts/...`
   - API calls: `/marts/api/...`
   - WebSocket calls: `/marts/ws/...`

7. Marts-specific operational files were added:

   - `.env.example`
   - `.gitignore`
   - `README.md`
   - `nginx.conf.example`
   - `scripts/check-env.sh`
   - `scripts/start.sh`
   - `scripts/build-frontend.sh`
   - `scripts/health-check.sh`

8. Python and shell syntax checks have passed.

9. The Marts isolation audit was completed:

   - Route-level notifications, broker, market-data, wallet, monitoring,
     webhook, and public URL settings use `MARTS_*` names.
   - Marts loads its local `marts/.env`.
   - The only approved database fallback remains `DATABASE_URL`.
   - The frontend development proxy defaults to the private backend port `8090`.
   - No remaining generic AllMart environment references were found in
     `marts/src/`.

10. The Marts environment template and README were updated with the names and
    routing rules required by the isolated service.

11. This setup phase is now authorized to install the declared dependencies,
    use only `DATABASE_URL` or an explicitly configured `MARTS_DATABASE_URL`,
    run the Marts Alembic migration, and configure the `/marts` serving path.
    `SUPABASE_DB_URL` is explicitly excluded from the Marts setup.

12. The declared Python dependencies were installed in the Replit Python
    environment. The existing Marts `requirements.txt` remains the source list;
    no AllMart pnpm dependency was changed.

13. The Alembic environment was repaired to:

    - Resolve `MARTS_DATABASE_URL` first and `DATABASE_URL` second.
    - Load the extracted Marts models as migration metadata.
    - Use synchronous PostgreSQL SQLAlchemy connections consistently.
    - Fail clearly when neither database URL is available.

14. A read-only probe using only `DATABASE_URL` reached the managed PostgreSQL
    database and found no public tables. `SUPABASE_DB_URL` was not read or
    modified.
